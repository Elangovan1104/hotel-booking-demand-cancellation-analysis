# 🏨 Hotel Booking Demand & Cancellation Analysis

## 📌 Project Overview
This project analyzes hotel booking demand and cancellation trends using **MySQL** and **Power BI**.  
The objective is to identify patterns in booking behavior, optimize revenue strategies, and reduce cancellation impact.

---

## 🎯 Business Objectives
- Analyze booking trends across seasons and hotel types
- Identify key factors influencing cancellations
- Measure revenue performance using ADR
- Understand customer segmentation
- Provide data-driven recommendations for revenue optimization

---

## 🛠️ Tools & Technologies Used
- **MySQL** – Data cleaning & transformation
- **Power BI** – Data modeling & dashboard creation
- **DAX** – KPI calculations
- **Excel/CSV** – Raw dataset handling

---

## 📊 Key KPIs Developed
- ✔ Total Bookings
- ✔ Cancellation Rate
- ✔ Average Daily Rate (ADR)
- ✔ Lead Time Analysis
- ✔ Occupancy Trends
- ✔ Revenue Insights

---

## 🧹 Data Preparation Techniques
- Data Cleaning (Handling NULLs & duplicates)
- JOIN operations for data enrichment
- GROUP BY for segmentation
- Foreign key relationships
- Data modeling using star schema

---

## 📈 Dashboard Features
- Resort vs City hotel performance comparison
- Season-wise booking trends
- Cancellation pattern analysis
- Customer segmentation insights
- Drill-through functionality
- Interactive slicers

---

---

## 💡 Key Insights
- Higher lead time increases cancellation probability
- Resort hotels show seasonal demand peaks
- ADR varies significantly by market segment
- Online travel agents contribute higher booking volume

---

## 🚀 Conclusion
This project demonstrates end-to-end business intelligence workflow including data preprocessing, relational modeling, KPI creation, and interactive dashboard development.
